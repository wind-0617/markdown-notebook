以下是一个自动完成所有步骤的脚本，支持 **Linux/macOS**（Bash）和 **Windows**（PowerShell）。请根据你的操作系统选择对应的脚本。

---

## 方案一：Bash 脚本（Linux/macOS）

将以下内容保存为项目根目录下的 `run.sh`，并赋予执行权限：

```bash
#!/bin/bash

# 进入脚本所在目录（即项目根目录）
cd "$(dirname "$0")"

echo "📁 当前目录: $(pwd)"

# 1. 创建虚拟环境（如果不存在）
if [ ! -d "venv" ]; then
    echo "🔧 创建虚拟环境..."
    python3 -m venv venv
fi

# 2. 激活虚拟环境
echo "🔌 激活虚拟环境..."
source venv/bin/activate

# 3. 安装依赖（优先使用根目录的 requirements.txt，若存在）
if [ -f "requirements.txt" ]; then
    echo "📦 安装依赖（根目录 requirements.txt）..."
    pip install -r requirements.txt
elif [ -f "backend/requirements.txt" ]; then
    echo "📦 安装依赖（backend/requirements.txt）..."
    pip install -r backend/requirements.txt
else
    echo "⚠️  未找到 requirements.txt，跳过安装"
fi

# 4. 进入 backend 并启动 app.py（后台运行）
echo "🚀 启动后端服务..."
cd backend
python app.py &
APP_PID=$!

# 等待服务就绪（根据实际情况调整秒数）
echo "⏳ 等待服务启动（2秒）..."
sleep 2

# 5. 自动打开浏览器
echo "🌐 打开浏览器访问 http://127.0.0.1:5000"
if command -v xdg-open &> /dev/null; then
    xdg-open http://127.0.0.1:5000
elif command -v open &> /dev/null; then
    open http://127.0.0.1:5000
else
    echo "请手动打开浏览器访问 http://127.0.0.1:5000"
fi

# 等待用户按 Ctrl+C 终止服务
echo "✅ 服务已启动，按 Ctrl+C 终止"
wait $APP_PID
```

**使用方法**：
```bash
chmod +x run.sh   # 仅首次需要
./run.sh
```

## 方案二：PowerShell 脚本（Windows）

将以下内容保存为项目根目录下的 `run.ps1`：

```powershell
# 进入脚本所在目录（项目根目录）
Set-Location $PSScriptRoot
Write-Host "📁 当前目录: $(Get-Location)"

# 1. 创建虚拟环境（如果不存在）
$venvPath = ".\venv"
if (-not (Test-Path $venvPath)) {
    Write-Host "🔧 创建虚拟环境..."
    python -m venv venv
}

# 2. 激活虚拟环境
Write-Host "🔌 激活虚拟环境..."
& .\venv\Scripts\Activate.ps1

# 3. 安装依赖（优先根目录，其次 backend）
if (Test-Path "requirements.txt") {
    Write-Host "📦 安装依赖（根目录 requirements.txt）..."
    pip install -r requirements.txt
} elseif (Test-Path "backend\requirements.txt") {
    Write-Host "📦 安装依赖（backend\requirements.txt）..."
    pip install -r backend\requirements.txt
} else {
    Write-Host "⚠️  未找到 requirements.txt，跳过安装"
}

# 4. 进入 backend 并启动 app.py（后台运行）
Write-Host "🚀 启动后端服务..."
Set-Location backend
$process = Start-Process -FilePath "python" -ArgumentList "app.py" -PassThru -NoNewWindow

# 等待服务启动
Write-Host "⏳ 等待服务启动（2秒）..."
Start-Sleep -Seconds 2

# 5. 打开浏览器
Write-Host "🌐 打开浏览器访问 http://127.0.0.1:5000"
Start-Process "http://127.0.0.1:5000"

# 提示终止方式
Write-Host "✅ 服务已启动，按 Ctrl+C 终止（或关闭终端）"
# 保持脚本运行，直到用户按 Ctrl+C
try {
    Wait-Process -Id $process.Id
} catch {
    # 用户中断时退出
}
```

**使用方法**：
```powershell
# 若首次运行需允许脚本执行
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\run.ps1
```

---

## 注意事项

1. **依赖文件位置**：脚本会优先查找项目根目录下的 `requirements.txt`，若不存在则查找 `backend/requirements.txt`，请根据实际情况放置。
2. **Python 命令**：Bash 脚本使用 `python3`，PowerShell 使用 `python`，确保系统 PATH 中有对应命令。
3. **端口占用**：若 `5000` 端口已被占用，`app.py` 可能启动失败，请提前关闭占用进程。
4. **服务终止**：Bash 脚本使用 `wait` 等待服务进程，按 `Ctrl+C` 可同时终止脚本和服务；PowerShell 使用 `Wait-Process` 类似。
5. **自动打开浏览器**：若系统不支持自动打开（如无图形界面），脚本会给出提示，手动访问即可。
