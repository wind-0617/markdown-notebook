## 0. 环境准备

**一键启动**：Windows 双击 `run.cmd`（或 `.\run.ps1`）；macOS/Linux 执行 `./run.sh`。
脚本自动建 venv（失败回退 `backend/.deps`）、装依赖、起服务、开浏览器；
参数：`-Reinstall` 重装依赖、`-Stop` 停服务；bash 侧 `REINSTALL=1` / `NO_BROWSER=1` / `--stop`。

手动方式：

```bash
# Python 3.10+，Windows / macOS / Linux 均可
cd backend
pip install -r requirements.txt     # 或免虚拟环境：
#   pip install --no-cache-dir --target .deps -r requirements.txt
python app.py                       # 启动后访问 http://127.0.0.1:5000

# 环境自检（无需浏览器，验证执行器/参数解析/全部 API）
python _selftest.py                 # 期望输出 SELFTEST OK
python _smoke.py                    # 期望输出 SMOKE OK
```

可选环境变量（见 `backend/config.py`）：

| 变量 | 默认 | 说明 |
|------|------|------|
| `PORT` / `HOST` | 5000 / 127.0.0.1 | 服务监听 |
| `EXECUTOR_MODE` | `local` | `local`=subprocess，`docker`=沙箱容器 |
| `EXEC_TIMEOUT` | 30 | 代码执行超时（秒） |
| `EXEC_TMP_DIR` | 系统临时目录 | 执行器工作目录根（生产可指向 tmpfs） |
| `AI_BASE_URL` / `AI_API_KEY` / `AI_MODEL` | - | AI 助手（可指向 Ollama） |

## 2. 阶段二：交互增强（第 4-6 周）

### FR-07 交互参数块
语法（注释声明，代码照常可读）：

```python
# @param n 样本量 slider min=10 max=1000 step=10 default=100
# @param algo 算法 select options=bubble,quick default=quick
# @param show_plot 显示图形 checkbox default=true
```

解析与执行链路：
- 后端：`parsers/param_parser.py` → `build_executable_code()` 把声明行替换为头部赋值；
- 前端：`js/controls.js` 渲染控件，`js/preview.js` 把控件挂到对应 `nb-block`。

### FR-08 参数联动执行
已实现：控件 `change` 事件防抖 350ms 后自动重新执行本块。
可调点在 `js/preview.js` 的 `App.debounce(..., 350)`。

## 4. 安全基线（每次发布检查）

1. 生产必须 `EXECUTOR_MODE=docker`（沙箱断网、`--read-only`、内存/CPU 限额见
   `executors/base.py::_docker_command`）；
2. `EXEC_TIMEOUT` 上限 120s 已在基类硬编码，防滥用；
3. 笔记文件名白名单校验在 `note_service._safe_path`，禁止路径穿越；
4. Shell 执行器可触达宿主系统，公网部署时考虑从注册表移除。
