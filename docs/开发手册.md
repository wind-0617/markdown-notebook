## 0. 环境准备

**一键启动（全栈）**：Windows 双击 `run.cmd`（或 `.\run.ps1`）；macOS/Linux 执行 `./run.sh`。
脚本自动：建 venv（失败回退 `backend/.deps`）→ 装 Python 依赖 → **构建前端**
（`npm install && npm run build`，已有 `frontend/dist` 则跳过）→ 起服务 → 开浏览器。
参数：`-Reinstall` 重装依赖、`-Stop` 停服务；bash 侧 `REINSTALL=1` / `NO_BROWSER=1` / `--stop`。

**分离开发（推荐日常）**：

```bash
# 终端 1：后端纯 API（:5000）
cd backend && python app.py

# 终端 2：前端 Vite dev server（:5173，/api 自动代理到 5000，改代码热更新）
cd frontend && npm install && npm run dev
```

手动装后端依赖：

```bash
cd backend
pip install -r requirements.txt
#   或免虚拟环境：pip install --no-cache-dir --target .deps -r requirements.txt
python _selftest.py                 # 期望 SELFTEST OK（执行器/参数层）
python _smoke.py                    # 期望 SMOKE OK（全部 API + 信封 + 搜索）
```

可选环境变量（见 `backend/config.py`）：

| 变量 | 默认 | 说明 |
|------|------|------|
| `PORT` / `HOST` | 5000 / 127.0.0.1 | 服务监听（Vite 代理读同名 `PORT`） |
| `EXECUTOR_MODE` | `local` | `local`=subprocess，`docker`=沙箱容器 |
| `EXEC_TIMEOUT` | 30 | 代码执行超时（秒，上限硬编码 120） |
| `EXEC_TMP_DIR` | 系统临时目录 | 执行器工作目录根（生产可指向 tmpfs） |
| `NB_PYTHON` / `NB_JAVA` / `NB_GO` | 自动探测 | 显式指定解释器路径（打包版尤其有用） |
| `AI_BASE_URL` / `AI_API_KEY` / `AI_MODEL` | - | AI 助手（可指向 Ollama） |
| `CORS_ORIGINS` | 空（同源） | 逗号分隔白名单。**禁止 `*` 长期开启** |

## 1. v0.3 架构约束（必读）

1. **后端只做 JSON**。业务路由一律进 `backend/routes/*.py` 蓝图，且必须用
   `api_response.ok()/fail()` 返回统一信封——禁止裸 `jsonify`。
   唯一例外：`app.py::_mount_static` 纯静态托管 `frontend/dist`（exe 双击即用；
   绝不写任何服务端模板/页面拼装）。
2. **前端不写死 URL**。所有请求经 `src/api/client.js`（解析信封、抛 `ApiError`），
   资源封装放 `src/api/*.js`；基址来自 `import.meta.env.VITE_API_BASE_URL`。
   非 fetch 场景（如导出下载 `<a href>`）用 `client.js` 导出的 `API_BASE` 拼，
   同样不得出现字面量 `http://localhost:…`。
3. **错误按 `error.code` 分支，`message` 只给人看**。新增错误场景先在
   `api_response.py` 错误码表登记，再同步 `docs/API文档.md`。
4. **每完成一个功能，`docs/dev_log.md` 追加一条记录**（问题/原因/方案/涉及文件/备注），
   这是硬性纪律，PR 不带日志视为未完成。
5. 前端新组件按 `src/components/Xxx.js` ES Module 导出；Monaco 相关保持
   经 `App.js` 动态 `import("./Editor.js")` 的懒加载结构（首屏体积关键）。
   **所有弹窗复用 `Modal.js`**（`openModal/confirmModal/promptModal`），不要再各写一套遮罩。
6. 搜索索引（`backend/.search_index/`）、`node_modules/`、`frontend/dist/`、
   `*.ai-chat.json` 均已 gitignore，不要提交；索引损坏点 🔄 或 `POST /api/search/rebuild`。
7. **文件名一律"显式拒绝非法"，不做静默净化**：任何写盘入口（新建/保存/重命名/
   聊天记录）的 name 校验走同一套白名单，含 `/ \ ..` 或非 `.md` 直接 `NOTE_NAME_INVALID`。
   AI 聊天记录 `<笔记>.ai-chat.json` 与笔记同名同目录，删除/改名由后端联动，前端不各自实现。

## 5. 安全基线（每次发布检查）

1. 生产建议 `EXECUTOR_MODE=docker`（断网、`--read-only`、内存/CPU 限额见
   `executors/base.py::_docker_command`）；
2. `EXEC_TIMEOUT` 上限 120s 基类硬编码；
3. 文件名白名单 + realpath 前缀校验：`note_service._safe_path`（返回**清洗后真名**，
   一切响应以此为准）；
4. CORS 不默认开启、绝不用 `*`；推送前跑 `python tools/scan_secrets.py`（暂存区扫描）；
5. Shell/Java/Go 执行器可触达宿主系统，公网部署时按需裁剪注册表。
