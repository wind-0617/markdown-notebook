# 项目规划文档

> 项目：Markdown 可执行笔记工具 ｜ 状态：V1.0（依据《开发文档》整理）

## 1. 开发里程碑

| 阶段 | 周期 | 里程碑 | 交付物 | 框架现状 |
|------|------|--------|--------|---------|
| 阶段一：MVP | 第 1-3 周 | 可编辑 + 可执行 Python 的 Web 编辑器 | 可运行 Demo | ✅ 骨架已生成 |
| 阶段二：交互增强 | 第 4-6 周 | 交互参数组件 + 结果持久化 | 功能增强版 | 🟡 控件已可渲染，FR-09 待做 |
| 阶段三：智能增强 | 第 7-9 周 | AI 助手 + Git 同步 | 完整版本 | 🟡 服务层骨架已就绪 |
| 测试与部署 | 第 10 周 | 功能测试、安全审计、上线 | 正式发布 | ⬜ |

## 2. 技术选型

| 层级 | 技术 | 选型理由 |
|------|------|----------|
| 后端框架 | Flask | 轻量灵活，Python 生态完善 |
| 前端编辑器 | Monaco Editor | VS Code 同款，体验优秀 |
| 前端框架 | 原生 HTML/CSS/JS | 降低复杂度，便于理解修改 |
| UI 样式 | 自定义 CSS 主题变量（v0.2 起替代 Tailwind CDN） | 深浅色一键切换，离线可用，无 CDN 依赖 |
| 代码执行 | subprocess + Docker | 开发用 subprocess，生产用 Docker 沙箱 |
| AI 集成 | OpenAI 兼容 API | 支持 DeepSeek/GPT/Ollama，可替换 |
| 版本控制 | GitPython / 命令行 Git | 成熟方案 |
| 数据存储 | 本地文件系统 (.md) | 标准格式，可移植 |

## 3. 项目结构

```
markdown-notebook/
├── backend/                         # 后端服务（Flask）
│   ├── app.py                       # 应用入口 + 全部 API 路由
│   ├── config.py                    # 环境驱动配置
│   ├── requirements.txt
│   ├── executors/                   # 代码执行引擎（注册表模式）
│   │   ├── base.py                  # 基类：超时/临时目录/docker 包装
│   │   ├── python_executor.py       # Python
│   │   ├── js_executor.py           # JavaScript (node)
│   │   └── shell_executor.py        # Shell (cmd/sh)
│   ├── parsers/
│   │   ├── markdown_parser.py       # 渲染 + 代码块提取
│   │   └── param_parser.py          # @param 交互参数解析
│   ├── services/
│   │   ├── note_service.py          # 笔记 CRUD（路径安全）
│   │   ├── ai_service.py            # OpenAI 兼容调用
│   │   └── git_service.py           # Git 状态/提交/推送
│   └── notebooks/                   # .md 笔记存储目录
├── frontend/
│   ├── index.html
│   ├── css/style.css
│   └── js/  app.js · editor.js · preview.js · executor.js · controls.js · ai-panel.js
├── docker/  Dockerfile（沙箱镜像）· docker-compose.yml
├── docs/    需求分析 · 项目规划 · 开发手册 · API文档
└── README.md
```

## 4. 风险评估

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|---------|
| 代码执行安全漏洞 | 高 | 中 | Docker 沙箱（断网/限额/只读），超时强杀 |
| AI API 调用成本 | 中 | 中 | 支持本地模型（Ollama），用户自备 Key |
| Monaco 学习曲线 | 低 | 中 | CDN loader + 单文件封装 `editor.js` |
| 多语言执行兼容性 | 中 | 低 | 分阶段：先 Python，JS/Shell 骨架已就位 |
| 项目范围蔓延 | 高 | 高 | 严格按三阶段推进，每阶段有明确交付物 |
