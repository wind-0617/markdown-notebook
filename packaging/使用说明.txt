■ 这是什么
  单文件桌面级笔记工具：Markdown 笔记中直接嵌代码块，浏览器里一键运行、
  拖滑块调参、结果写回文档；🔍 全文搜索（中文分词+高亮）；⚙️ 可配置任意
  OpenAI 兼容 AI 服务。标准 .md 存储，无数据库、无厂商锁定。

■ 快捷键
  Shift+Enter 运行光标处代码块 ｜ Ctrl+S 保存 ｜ Ctrl+K 全文搜索

■ 快速开始（3 步）
  1. 解压本 zip 到任意目录（建议纯英文路径，如 D:\notebook\）
  2. 双击 markdown-notebook.exe
     → 会弹出一个黑色控制台窗口（这是服务本体，请保持开着）
     → 约 1~3 秒后自动打开浏览器 http://127.0.0.1:5000
  3. 开始使用；关闭控制台窗口即停止服务

■ 笔记管理（v0.3.1）
   鼠标悬停在左侧「📁 笔记」列表项上，出现三个按钮：
     ✏️ 重命名（弹窗改 name，自动补 .md，搜索索引/打开中的标签/AI 记录同步跟随）
     ⬇️ 导出（浏览器直接下载原 .md 文件，中文文件名正常）
     🗑️ 删除（二次确认；不可恢复，该笔记的 AI 聊天记录一并删除）
   AI 聊天记录现在会自动保存：与笔记同名（如「示例笔记.ai-chat.json」），
   打开哪篇笔记就恢复哪篇的对话；🧹 按钮清空（有二次确认）。
   AI 设置（⚙️）新增「测试连接」按钮，填完即时验证；API Key 可点眼睛图标
   切换明文查看。配置保存在浏览器里——换浏览器/换端口入口需重新填一次。

■ 支持的代码语言（v0.3）
   Python / JavaScript / Shell / Java / Go 五种。界面底部状态栏有"语言环境灯"
   （🐍📦💲☕🐹），❌ 表示本机未装对应工具链——运行时会弹出安装引导：
     · Python 3.x（推荐：装完勾选 Add to PATH；执行自动隔离，不污染环境）
     · Node.js（JavaScript 块）
     · JDK 11+（Java 块；公共类必须命名 Main，采用 java Main.java 单文件模式）
     · Go（Go 块；须含 func main()）
   也可用环境变量显式指定：NB_PYTHON / NB_JAVA / NB_GO 指向对应可执行文件。
   不装任何语言环境也能用：编辑、预览、全文搜索、AI 助手均不依赖它们。

■ 数据在哪里
  · 笔记保存在 exe 同级的 notebooks\ 目录（标准 .md 文件）
  · AI 聊天记录在 notebooks\ 下的 <笔记同名>.ai-chat.json（随笔记删除/改名）
  · 全文搜索索引在 exe 同级 .search_index\（可整目录删除，会自动重建；
    或在界面 🔍 页签点 🔄 手动重建）
  · 换目录/换电脑 = 整个文件夹拷走即可
  · 想指定别的位置：新建环境变量 NOTEBOOKS_DIR=D:\我的笔记 后重启
  · 端口被占用时：设环境变量 PORT=5001 后重启

■ Docker 沙箱模式（可选进阶）
  安装 Docker Desktop 后，先构建镜像（需源码仓库 docker/ 目录）：
      docker build -t markdown-notebook-sandbox:latest .
  再以环境变量启动 exe：
      set EXECUTOR_MODE=docker && markdown-notebook.exe
  此模式代码在断网只读容器中执行，打开陌生笔记时更安全。

■ 常见问题
  Q: 双击后闪退/浏览器没开？
  A: 看控制台窗口的报错。端口被占就设 PORT；浏览器没自动开就手动访问
     控制台里显示的地址。SmartScreen 拦截时点「更多信息→仍要运行」。
  Q: 杀软报毒？
  A: PyInstaller 单文件 exe 的常见误报（无签名的自解压行为）。
     本产物由 GitHub Actions 公开构建（见 Release 页 workflow 日志），
     源码完全开放，可自行 clone 后运行 build.bat 重新构建验证。
  Q: 想开机自启 / 常驻服务？
  A: 把 exe 快捷方式放入 shell:startup，或任务计划程序登录时运行。
