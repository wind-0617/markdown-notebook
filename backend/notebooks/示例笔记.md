```python
squares = [i * i for i in range(1, 8)]

```

## 2. 交互式参数（阶段二 FR-07/08）

拖动预览区出现的滑块/下拉框，代码会自动重新执行：

```python
# @param n 项数 slider min=2 max=25 step=1 default=12
# @param style 输出风格 select options=列表,竖排 default=列表
def fib(k):
    a, b = 0, 1
    out = []
    for _ in range(int(k)):
        out.append(a)
        a, b = b, a + b
    return out

seq = fib(n)
if style == "竖排":
    for i, x in enumerate(seq, 1):
        print(f"fib({i}) = {x}")
else:
    print(seq)
```
